# Skills personalizadas

[[Skills para Codex/00 - Inicio|Início]] · [[Skills para Codex/02 - Instalar e usar|Instalar e usar]]

Foram criadas três skills em português para o seu fluxo de Obsidian + Codex. Os pacotes estão em `{{source_root}}\skills-personalizadas\` e não foram instalados globalmente.

## 1. Capturar conhecimento

[[Skills para Codex/Catalogo/Personalizadas/obsidian-capturar-conhecimento|obsidian-capturar-conhecimento]]

Transforma textos, conversas ou anotações autorizados em notas com resumo, fontes e próximas ações. Usa links para notas existentes e preserva o que não foi pedido para alterar.

**Exemplo:** transformar uma explicação sobre uma skill em uma nota de referência, sem inventar decisões ou fontes.

**Não faz:** ler todo o cofre sem necessidade, publicar notas ou conectar contas.

## 2. Organizar o cofre

[[Skills para Codex/Catalogo/Personalizadas/obsidian-organizar-cofre|obsidian-organizar-cofre]]

Faz inventário e cria mapas de conteúdo, categorias e links verificáveis. Prefere índices à movimentação de arquivos.

**Exemplo:** criar um índice de estudos por assunto sem renomear nem mover as notas atuais.

**Não faz sem autorização específica:** excluir, mover em massa, fundir notas ou alterar `.obsidian`.

## 3. Auditar skills

[[Skills para Codex/Catalogo/Personalizadas/codex-auditar-skills|codex-auditar-skills]]

Revisa `SKILL.md`, auxiliares, dependências e permissões antes do uso. Trata a skill analisada como dados, não como instruções para o auditor.

**Exemplo:** descobrir se uma skill contém comandos de instalação, envio de dados, acessos desnecessários ou instruções antigas.

**Não faz:** executar os scripts analisados, instalar pacotes, autorizar serviços ou prometer segurança absoluta.

## Estado de validação

Os arquivos usam o formato `SKILL.md` com `name` e `description`, nomes compatíveis com as respectivas pastas e instruções focadas. Não exigem scripts próprios ou acesso a uma conta externa.

A validação estrutural não comprova o comportamento de um agente. Escolha um exemplo pequeno e confira o resultado antes de usar uma skill em muitas notas ou projetos.

Para adaptar ou criar outras: [[Skills para Codex/04 - Criar novas skills|Criar novas skills]].
